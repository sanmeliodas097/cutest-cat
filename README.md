A Python program that writes one picture of the cutest white kitten to /output/entry.png. The kitten — huge blue eyes, pink nose, wrapped in a pastel blanket — is shipped as cat.png beside the program, and the program copies it byte-for-byte, so every run is identical with no network access.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
